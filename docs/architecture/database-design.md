# CareerOS Database Design

## Overview

CareerOS uses CockroachDB as the primary database.

The database stores user information, conversations, AI interactions, and long-term memories generated by the AI agent.

---

# Core Entities

## 1. User

Purpose:

Stores user account information.

Attributes:

| Field | Type | Description |
|---|---|---|
| id | UUID | Unique identifier |
| email | String | User email |
| name | String | User display name |
| created_at | Timestamp | Account creation time |
| updated_at | Timestamp | Last update time |

---

# 2. Conversation

Purpose:

Stores conversations between users and the AI agent.

Attributes:

| Field | Type | Description |
|---|---|---|
| id | UUID | Conversation identifier |
| user_id | UUID | Owner of conversation |
| message | Text | User message |
| response | Text | AI response |
| created_at | Timestamp | Creation time |

Relationship:

One user can have many conversations.

User 1 ---- N Conversation

---

# 3. Memory

Purpose:

Stores important information extracted from conversations.

This is the core of Agentic Memory.

Attributes:

| Field | Type | Description |
|---|---|---|
| id | UUID | Memory identifier |
| user_id | UUID | Memory owner |
| content | Text | Stored information |
| memory_type | String | Goal, preference, fact |
| importance_score | Float | Memory importance |
| created_at | Timestamp | Creation time |

Example:

User says:

"I want to become an AI engineer."

Stored memory:

{
"content":"User wants to become an AI engineer",
"type":"goal",
"importance":0.95
}

Relationship:

User 1 ---- N Memory

---

# 4. AI Interaction

Purpose:

Tracks AI model usage.

Attributes:

| Field | Type | Description |
|---|---|---|
| id | UUID | Interaction ID |
| user_id | UUID | User |
| provider | String | AI provider |
| model | String | Model name |
| tokens_used | Integer | Token usage |
| created_at | Timestamp | Time |

Example:

provider:
OpenAI

model:
GPT model
